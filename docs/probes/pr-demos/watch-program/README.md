# Pure watch evidence boundaries

New library interface, using synthetic local evidence rather than a deployment.
There is no prior installed command to compare. The recording shows the original
end included after a non-dividing cadence, safety separated from inactive
activation, an incomplete ended window refused, and a real breach retained
alongside a missing metric. Compensation stays NOT_EXECUTED.

```sh
python3 docs/probes/pr-demos/watch-program/demo.py
scriptreplay --log-out docs/probes/pr-demos/watch-program/output.log --log-timing docs/probes/pr-demos/watch-program/timing.log
```

The output-only recording and timing file can be downloaded and replayed with
`scriptreplay`; no inline player is assumed. This is a library demonstration,
not managed-unit, authenticated-reader or live-watch acceptance.
