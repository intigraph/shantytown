# Package versions and private addresses

The guard previously refused a pinned public wheel because its version looked
like a private address outside one repository-specific record exception. The
candidate recognizes explicit version spans in HTTP(S) paths and wheel/tar
filenames. Actual authorities, queries, fragments, adjacent leaks and ambiguous
representations still reach the original matcher. Parser failure keeps the
original text under scan.

Run `python3 docs/pr-demos/version-context/demo.py` from a checkout containing
base commit `830f142b39677fe89be576dfbaf2403dd75a829c`. It applies the same
controls to disposable copies of both matchers and invokes the real hook's
stdin protocol. It makes no network push and changes no installed hook.

The compact recording is `output.log`. Source-fixture evidence does not prove
hosted CI, independent review or installed propagation.
