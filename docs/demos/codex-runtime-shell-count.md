# Codex automatic-cycle terminal count

Codex automatic cycles query the local daemon's experimental `thread/backgroundTerminals/list` method. A complete zero permits the shell gate; positive or UNKNOWN results refuse. Claude's existing shell-count contract is unchanged.

The reader binds the daemon PID and Unix peer to the card's environment, and the current hook session UUID to its transcript header and the daemon's complete loaded-thread list. It rejects incomplete pagination, duplicate IDs, malformed responses and changed identity generations. It does not start or resume a thread, terminate terminals, copy credentials or infer zero from process enumeration. Unsupported versions and platforms remain UNKNOWN.

The final cycle boundary rechecks busy state and the input box after IPC. Checkpoint, worktree and lifecycle guards still apply.

A private live control on Codex 0.161.0 observed zero terminals, one terminal matching the yielded tool session, then zero after natural exit. This verifies the read seam; normal installation and an actual pending cycle remain separate acceptance gates.
